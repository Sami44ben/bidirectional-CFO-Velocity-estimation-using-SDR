# Bidirectional CFO Separation on Free-Running SDRs

Code, data and LaTeX source for the paper

> M. E. Benattia and H. Arslan, *Experimental Evaluation of Bidirectional CFO Separation under
> Peer and Environmental Motion*, submitted to IEEE ICC 2027.

It is the hardware follow-up to the simulation letter
*Bidirectional CFO Separation for Radial Velocity Estimation in 5G NR TDD V2X Links*
([arXiv:2609.02258](https://arxiv.org/abs/2609.02258)).

## The idea in three lines

In a TDD link each direction measures a carrier frequency offset (CFO) that is the sum of the
propagation Doppler and the offset between the two oscillators. The oscillator term flips sign
when the transmit/receive roles swap and the Doppler does not, so

```
half sum        (CFO_DL + CFO_UL) / 2   ->  Doppler  ->  radial velocity  v = c * f_d / f_c
half difference (CFO_DL - CFO_UL) / 2   ->  oscillator offset
```

On real radios the two directions are measured ~78 ms apart, and the oscillator drift during that
gap biases the Doppler by `-r * gap / 2`. This repository measures that bias on two ADALM-Pluto
SDRs and corrects it (causal drift compensation, epoch alignment).

## Repository layout

```
paper/          LaTeX source of the paper, its figures and the compiled PDF
  ICC2027_SDR.tex         main file (pdflatex -> bibtex -> pdflatex x2)
  results_numbers.tex     every measured number, GENERATED by analysis/make_numbers.py
  figures/                figure PDFs + editable MATLAB .fig files
acquisition/    the measurement chain that drives the two radios (Python)
analysis/       estimators and the scripts that turn captures into numbers (Python)
matlab/         the scripts that draw the paper figures (MATLAB)
data/           the captures used in the paper (see data/README.md)
docs/           glossary of the variable names used in captures and code
```

Each folder has a short README where needed. The rule that holds everything together:
**no number is typed into the paper.** `analysis/make_numbers.py` writes them all into
`paper/results_numbers.tex`, so re-running it updates every table, figure caption and paragraph.

## Hardware

- 2 x ADALM-Pluto, free-running TCXOs, each with one monopole on its TX port and one on its RX port
- one host PC driving both radios over USB
- 2.3 GHz carrier, 60 kHz subcarrier spacing, 64-point FFT, 60 active subcarriers,
  30 comb pilots, 140 OFDM symbols per burst (all knobs in `acquisition/config.py`)

## Requirements

- Python 3.13 with the packages in `requirements.txt`
  (`pyadi-iio` and libiio are needed only to talk to the radios; analysis works without them)
- MATLAB R2025a (no toolboxes) for the figures
- a LaTeX distribution (MiKTeX or TeX Live) for the paper

```bash
pip install -r requirements.txt
```

On Windows, set `LIBIIO_DIR` to the folder that holds `libiio.dll` if it is not installed in
`C:\Program Files\libiio\bin`.

## Reproduce the paper from the recorded data

1. **Get the data.** Five captures are larger than GitHub allows (100 MB) and are attached to the
   GitHub Release of this repository. Download them into `data/captures/`
   (list in `data/README.md`).

2. **Regenerate every number** (from `analysis/`):

   ```bash
   python pilot_density.py ../data/captures/capture_icc_WARM_0922_0807.mat --json ../paper/figures/fig_density_numbers.json
   python fan_compare.py ../data/captures/capture_icc_FAN_OFF1.mat ../data/captures/capture_icc_FAN_ON.mat ../data/captures/capture_icc_FAN_ON_FAST.mat ../data/captures/capture_icc_FAN_OFF2.mat --rpm 0,100,800,0 --radius 0.15 --fig ../paper/figures/fig_fan.pdf
   python make_numbers.py --warm ../data/captures/capture_icc_WARM_0922_0807.mat --sep "../data/captures/capture_icc_SEP_0922_0823_*.mat" --gap-warm "../data/captures/capture_icc_GAP_0922_0840_*.mat" --gap-cold "../data/captures/capture_icc_GAP_0922_0912_*.mat" --move ../data/captures/capture_icc_MOVE_REF_test2.mat --density-json ../paper/figures/fig_density_numbers.json --fan-json ../paper/figures/fig_fan_numbers.json --sim "../data/emulated/OFFLINE_capture_icc_SEP_*.mat"
   ```

3. **Redraw the figures** (MATLAB, from `matlab/`):

   ```matlab
   fig_separation_m; fig_gap_m; fig_motion_m; fig_density_m   % fig_density_m takes ~10 min
   ```

4. **Build the paper** (from `paper/`): `pdflatex ICC2027_SDR`, `bibtex ICC2027_SDR`, then
   `pdflatex ICC2027_SDR` twice.

## Record new data

From `acquisition/`, with both radios plugged in:

```bash
python selftest.py                 # no hardware needed: checks the DSP and the whole chain offline
python campaign.py                 # one run with the settings in config.py
python run_matrix.py sep --dry     # the automated sweeps used in the paper (warm / sep / gap)
```

Every setting can be overridden from the environment as `ICC_<NAME>` (e.g. `ICC_RUN_TAG`,
`ICC_GAP_S`, `ICC_FD_INJECT`), so batch runs never edit `config.py`. Captures are written to
`data/captures/capture_icc_<RUN_TAG>.mat`. Analyse any capture with

```bash
python ../analysis/analyze_icc.py ../data/captures/capture_icc_<RUN_TAG>.mat
```
